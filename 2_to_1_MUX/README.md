# 2:1 Multiplexer

## Objective
To design and verify a 2:1 multiplexer using Verilog HDL.

## Inputs and Output
- i0 – Input 0
- i1 – Input 1
- sel – Select line
- y – Output

## Working
- When sel = 0, y = i0
- When sel = 1, y = i1

## Verification
The design was simulated using Icarus Verilog and the waveform was viewed using GTKWave.

## Result
The 2:1 multiplexer was successfully designed and verified.
